# Additional provider sources

Research checked on November 9, 2026. Country views distinguish observed storefront prices from USD conversions. A public USD offer does not establish country eligibility.

## GLM Coding Plan

Z.ai's international Lite, Pro and Max plans are distinct from BigModel's China offers. The ZCode pricing page shows both full and discounted amounts. Subscription billing selection must establish the applicable period before automated changes are accepted.

- Pricing: https://zcode.z.ai/pricing.html
- Purchase: https://z.ai/subscribe
- Limits: https://docs.z.ai/devpack/overview

## Xiaomi MiMo

The official Token Plan Markdown includes individual and team tables, monthly and annual prices, USD and CNY amounts, and vendor credits. The catalog uses individual USD offers. Credits are not token counts. Annual totals are billed annually. Token Plan quota and standard API balances are separate.

- https://mimo.mi.com/static/docs/price/token-plan.md
- https://mimo.mi.com/static/docs/price/pay-as-you-go.md

## Command Code

Use commandcode.ai, not command.new. The public pricing page and documentation disagree about some included credits and estimated request counts. Display the subscription fee and processing-fee condition; hold conflicting benefits for review. The Provider plan charges a subscription in addition to usage.

- https://commandcode.ai/pricing
- https://commandcode.ai/docs/resources/pricing-limits

## Kimi

The official app is published by Moonshot AI with Apple app ID 6474233312. Preserve current Plus/Pro/Max/Ultra names separately from legacy Moderato/Allegretto/Allegro/Vivace names. English help pages include outdated membership rules. New Plus-and-higher coding plans use a rolling five-hour window without a weekly limit according to the updated rules. Confirm the purchase period before automatic price verification.

- https://www.kimi.com/code

## DeepSeek

The reviewed first-party material describes prepaid API billing, including when using DeepSeek Harness. No monthly subscription was confirmed. Reseller access must be attributed to the seller. The existing API pricing URL returned first-call documentation during research, so a future rate extractor needs a verified pricing-table source before it can update rates.

- https://www.deepseek.com/harness/data-processing/
- https://api-docs.deepseek.com/quick_start/pricing
